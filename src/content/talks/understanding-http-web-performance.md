With more people on low-bandwidth, low-powered mobile devices, performance is a
big part of the user experience. Mike Rudolph and I went back to our roots: how
the HTTP protocol works, and how to use it to optimize performance in creative
ways.

We covered how to measure performance, plus tips and tricks from our own work in
the industry.
